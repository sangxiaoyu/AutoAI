# JSON & SQL 格式化工具

一款简洁高效的在线 JSON 与 SQL 格式化工具，支持代码美化、压缩和双栏对比功能。

[在线使用](https://your-domain.com/JsonHelper/index.html)

## 功能特性

### JSON 格式化
- **格式化美化** - 自动缩进、规范化 JSON 结构
- **压缩功能** - 一键将 JSON 压缩为单行格式
- **语法验证** - 实时检测 JSON 语法错误
- **双栏对比** - 左右双栏对比两个 JSON 文件的差异
- **差异高亮** - 清晰显示新增、删除、修改的内容

### SQL 格式化
- **智能格式化** - 自动美化 SQL 语句结构
- **双栏对比** - 左右双栏对比两个 SQL 语句的差异
- **关键字高亮** - 区分显示 SQL 关键字和普通文本

### 通用功能
- **复制/下载** - 轻松复制结果或下载为文件
- **示例加载** - 内置示例数据，快速体验功能
- **响应式设计** - 完美适配桌面端和移动端
- **即时反馈** - Toast 消息实时提示操作状态

## 使用方法

### JSON 格式化
1. 在左侧或右侧输入框粘贴 JSON 内容
2. 点击 **格式化 & 对比** 按钮进行美化
3. 如果两侧都有内容，将自动对比差异
4. 点击压缩按钮可将 JSON 压缩为单行

### SQL 格式化
1. 切换到 **SQL 格式化** 标签页
2. 在左侧或右侧输入 SQL 语句
3. 点击 **格式化 & 对比** 按钮
4. 查看美化后的结果和差异对比

### 快捷操作
| 按钮 | 功能 |
|------|------|
| 👁 | 加载示例数据 |
| 🗑 | 清空输入框 |
| 📋 | 复制到剪贴板 |
| ⬇ | 复制结果 |
| 💾 | 下载为文件 |
