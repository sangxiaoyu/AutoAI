## 🚀 快速开始

### 方式一：直接打开

```bash
# 克隆项目
git clone https://github.com/sangxiaoyu/AIToAI.git

# 进入目录
cd AIToAI

# 直接用浏览器打开
open main.html
```

### 方式二：本地服务器

```bash
# Python
python -m http.server 8080

# Node.js
npx serve .

# 然后访问
http://localhost:8080/main.html
```
